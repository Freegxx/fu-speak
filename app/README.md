# fu-speak uni-app 客户端

fu-speak 学习端应用,基于 uni-app 开发,支持微信小程序和 App 打包。

## 功能模块

### 三个主要板块

1. **单词** - 词书学习与间隔复习
   - 选择词书(CET-4/6/英语二/我的口语生词)
   - 设置每日学习量
   - 复习优先,每日至少30个新词
   - 1-10熟练度评分,智能间隔复习
   - 本地存储学习进度

2. **口语** - AI实时语音对话练习
   - 多种日常场景(餐厅/购物/机场等)
   - 实时语音对话(当前为模拟演示)
   - 即时纠错反馈
   - 生词标记加入个人词书
   - 对话记录保存

3. **我的** - 个人中心与学习统计
   - 可选登录(手机号/微信)
   - 等级系统(学习时长=等级)
   - 月度学习日历(打卡可视化)
   - 等级说明与词汇量测试

## 技术栈

- **框架**: uni-app (Vue 2.x)
- **状态管理**: Vuex
- **数据存储**: uni.storage (本地优先)
- **样式**: scoped CSS

## 运行说明

### 1. 安装依赖

```bash
cd app
npm install
```

### 2. 开发运行

**微信小程序:**
```bash
npm run dev:mp-weixin
```
然后使用微信开发者工具打开 `dist/dev/mp-weixin` 目录

**H5:**
```bash
npm run dev:h5
```

### 3. 构建生产版本

**微信小程序:**
```bash
npm run build:mp-weixin
```

**H5:**
```bash
npm run build:h5
```

## 核心功能实现说明

### 单词学习算法

- **熟练度分数与复习间隔:**
  - 1-5分: 短期内重复(0.5-1天)
  - 6分: 1-2天后复习(当日脱离门槛)
  - 7分: 约14天后复习
  - 8分: 约45天后复习
  - 9-10分: 完全掌握,不再复习

- **每日队列生成:**
  - 复习词优先
  - 有新词时,每天至少30个新词
  - 其余名额分配给复习词
  - 总量不超过用户设定的每日学习量

### 学习时长统计

- **计时范围:**
  - 单词学习页前台时间
  - 口语对话进行时间
  
- **防挂机:**
  - 每日有效上限4小时
  - 切后台自动暂停

- **等级计算:**
  - 累计学习时长(小时) = 等级
  - 例:学习50小时 = Lv.50

### 数据存储

- **本地优先:** 使用 uni.storage 存储所有学习数据
- **数据类型:**
  - 单词进度(wordProgress)
  - 口语对话记录(conversations)
  - 个人生词(personalVocabulary)
  - 用户信息与学习时长(userInfo, studyTime)
