---

## 1. 产品概述

### 1.1 产品名称

**fu-speak**

### 1.2 产品定位

面向英语学习者的通用版学习应用，核心能力为：

1. **背单词**（词书 + 间隔复习）
2. **练口语**（日常场景 AI 实时语音对话 + 纠错）

两者相互独立，不强制绑定。

### 1.3 目标形态

- 用户端：可打包为**微信小程序**与 **App**（同一套客户端方案）
- 网页端 / 管理端：运营与内容管理
- 后端：统一 API 与账号体系（登录后云端同步）

### 1.4 仓库约定

- **单一仓库**：前后端、用户端、需求文档均放在本仓库（`Freegxx/fu-speak`），目录拆分实现阶段再定。

## 3. 信息架构（用户端）

用户端**只做三个板块**，保持简单：

| 板块 | 作用 |
|------|------|
| **单词** | 选词书后学习、复习、熟练度标记 |
| **口语** | 日常对话 AI 实时语音练习与即时纠错；生词可标记入库 |
| **我的** | 账号（可选登录）、等级、学时说明、词汇量测试、月度学习图 |

## 4. 功能需求：单词

### 4.1 词书

- 单词来源于**词书**，非零散词堆。
- **进入「单词」板块后，必须先选择词书，才能开始学习**；未选词书不进入学习流。
- **首期词书范围**：
  - 大学英语**四级**
  - 大学英语**六级**
  - **英语二**（考研英语二等）
  - **口语生词词书**（对话中标记的不熟悉词）
- 首期单词字段建议最少包含：单词、音标、中英释义、1–2 条例句、英式 / 美式发音资源。相关词等可二期。

### 4.2 每日学习量与队列凑法

- 每日学习单词数量由**用户自行设定**（例如 100）。
- 队列来源：
  1. **尚未进入学习池**的新词
  2. **到期需要复习**的词
- **凑法规则（已确认）**：
  - **复习优先**。
  - 若仍有未出现的新词：在凑满用户设定总量时，**每天至少安排 30 个以上新词**（有新词可抽时），其余名额给复习词。
  - 若到期复习词很多（例如超过 100）：仍遵守「有新词则每天至少 30+ 新词，其余为复习」；总量以用户设定为准。
  - 若**没有新词**：当日队列**全部为复习词**。

### 4.3 复习策略（艾宾浩斯 + 熟练度）

- 每个单词的再次出现时间依据 **艾宾浩斯遗忘曲线**，并与当次 **1–10 熟练度**联动。
- **脱离当日队列**：熟练度必须达到 **≥ 6 分**，该词当天才不再出现。
- **关键分数含义与间隔（已确认）**：

| 分数 | 含义 | 再次出现 |
|------|------|----------|
| **6** | 看到英文知道中文意思，或看到中文能对应英文；过一段时间可能忘记 | **一两天或几天内**再出现 |
| **7** | 更稳的熟悉 | 约 **10 天，或十几～二十几天**再出现 |
| **8** | 更牢固 | 约 **三四十天，或五六十天**再出现 |
| **9 / 10** | **完全记忆** | **不再进入复习队列**（学习完成） |
| **1–5** | 未达「当日脱离」 | 当天仍可能再次抽到；间隔按更短周期安排（具体表实现阶段可细化） |

> 说明：早期「熟悉 = 7、当日脱离 = 7」的约定，已更新为：**当日脱离门槛 = 6**；7 / 8 主要拉开复习间隔；9 / 10 毕业。

### 4.4 单词学习页交互

#### 4.4.1 出示方式（中英交替）

- **有时先展示中文**：用户可输入英文单词，验证是否正确。
- **有时先展示英文**：用户可输入中文释义，验证是否正确。
- **输入可选**：也可不输入，直接点击页面其他区域展开释义等信息，再标记熟练度。

#### 4.4.2 展开内容

点击页面其他区域后，可展示包括但不限于：

- 释义
- 读音相关信息
- 对应例句
- 其他相关单词（二期可增强）

#### 4.4.3 发音

- 提供发音入口，点击后朗读当前单词。
- 支持 **英式发音** 与 **美式发音** 切换或选择。

#### 4.4.4 进入下一词

- 用户**标记熟练度之后**，自动跳转到下一词。

### 4.5 熟练度控件（1–10）

- 页面底部为 **1–10 横向滑动 / 点选条**：
  - 最左为 **1**，最右为 **10**
  - 颜色由 **黄 → 深绿** 渐变
  - 横条在垂直方向上**适当加高**，便于点击
- **7 下方文案方向**：按记忆曲线说明「当日已脱离后，约十天至二十几天再出现」（与 4.3 一致，文案可微调）。
- **9 下方文案**：完全记忆，不再出现复习队列。
- **6 下方**建议补充说明：达到熟悉门槛，当日不再出现，一两天或几天内再复习。

## 5. 功能需求：口语

### 5.1 定位

- 口语模块与单词模块**解耦**，不要求围绕当前背词进行。
- 练习内容仅从**日常对话场景**产生。

### 5.2 AI 实时语音对话与纠错（已确认）

- 采用**实时语音通话**形式。
- 用户说完一句后：**语音转文字**。
- AI **及时以语音给予纠正**，**每句立刻改**，整体仍保持**对话形式**推进。

### 5.3 对话记录

- 系统**记录对话内容**（含转写文本等），支持用户回看历史对话（展示形态实现阶段再定）。

### 5.4 口语生词入库

- 日常对话过程中出现的**不熟悉单词**，用户可以**标记**。
- 被标记的词进入**另外的单词本**（口语生词词书，与四级 / 六级等考试词书区分）。
- 用户之后可在「单词」板块中**选择该词书**，按既有单词学习 / 复习流程学习这些词。

## 6. 功能需求：我的

### 6.1 登录与数据（已确认）

- **登录不是必须**。
- 未登录：学习数据**优先存本地**。
- 登录后：数据**同步到云端**。
- 登录方式支持：**手机号登录**、**微信登录**等。

### 6.2 等级与学时（已确认）

- **等级与累计学习时长挂钩**：学了多少小时，大致对应多少级（例如累计 N 小时 → N 级；具体展示文案可写「Lv.N」）。
- **学习时长统计规则**（须在「我的 / 等级说明」中向用户展示，用户可见）：
  - **计时范围**：单词学习页在前台停留的时间 + 口语对话进行中的时间。
  - **切到后台**：暂停计时。
  - **防挂机**：每日有效学时设上限（建议 **每天最多计入 4 小时**），超出部分不计入等级与打卡颜色依据的「有效学习时长」。
- 词汇量测试：提供能力测评结果；**首期不强制与等级挂钩**（等级以学时为主）。

### 6.3 词汇量测试

- 提供**词汇量测试**能力（题型与算法实现阶段再定）。

### 6.4 月度学习图（打卡风格）

- 以「月」为维度展示每日学习情况。
- 颜色依据**当日有效学习时长**（与 6.2 统计口径一致）：

| 当日学习时长 | 颜色 |
|--------------|------|
| **10 分钟以下** | **黄色** |
| **10 分钟及以上** | **浅绿色** |
| **30 分钟及以上** | **深绿色** |

## 7. 管理端（若依）首期范围建议

1. 词书与单词内容管理（四级 / 六级 / 英语二；音标、释义、例句、发音资源等）
2. 口语生词词书 / 用户标记生词的管理或查看
3. 用户与学习进度、学时与等级相关数据查看
4. 口语对话记录相关的基础管理（若需要运营侧查看）

---

## 8. 首期明确不做

为避免范围膨胀，**首期不做**：

- 社交排行
- 商城
- 多语言界面（产品界面国际化）
- 复杂游戏化
- 超出「日常场景模板」的 AI 自由漫聊

---

## 9. 非功能与约束（当前约定）

- **先完善需求与想法，再开始写业务代码**（本文档即该阶段产物）。
- 产品结构保持简单：用户端三个 Tab 为主。
- 本地优先、登录后云端同步；多端在登录账号下最终数据一致。
